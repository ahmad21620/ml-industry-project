01- activate the env


02- uvicorn app:app --reload


03- Chat UI: http://127.0.0.1:8000/
    Admin UI: http://127.0.0.1:8000/admin-ui
    API Docs: http://127.0.0.1:8000/docs


if server is starting ("application startup complete") but the webpages are not loading do the folloiwng:

    01- netstat -ano | findstr :8000
        you will find a listening port "TCP    127.0.0.1:8000   ...   LISTENING   12345"
        we need to kill it

    02- taskkill /PID 12345 /F
        replace the 12345 with the actual PID of the listening port
    
    03- python -m uvicorn app:app --host 127.0.0.1 --port 8000 --log-level debug --access-log
